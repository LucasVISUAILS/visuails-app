# VISUAILS Setup - Super Simple Steps

## ⚡ 5-Minute Deployment

You don't need to code. Just follow these 3 steps.

---

## Step 1️⃣: Create GitHub Account (2 minutes)

1. Go to **https://github.com/signup**
2. Enter your email
3. Create a password
4. Verify your email
5. ✅ Done!

---

## Step 2️⃣: Upload Files to GitHub (2 minutes)

### **Easiest Way:**

1. Go to **https://github.com/new**
2. Name it: `visuails-app`
3. Choose "Public"
4. Click "Create repository"
5. Click the "uploading an existing file" link
6. **Drag and drop all files from this folder** (the visuails-app folder) into GitHub
7. Click "Commit changes"
8. ✅ Done!

---

## Step 3️⃣: Deploy to Cloudflare (1 minute)

1. Go to **https://dash.cloudflare.com/signup** (or login if you have account)
2. Sign up for free
3. Click **"Pages"** in the left menu
4. Click **"Create a project"**
5. Click **"Connect to Git"**
6. Select your GitHub account
7. Select the **`visuails-app`** repository
8. Keep the settings as they are (Astro is auto-detected)
9. Click **"Save and Deploy"**
10. Wait 1-2 minutes...
11. ✅ **Your website is LIVE!** 🎉

Cloudflare will give you a URL like:
```
https://visuails-app-abc123.pages.dev
```

## 🆘 If Something Breaks

1. **Deployment failed?**
   - Go to Cloudflare Pages → visuails-app → Deployments
   - Look at the error log
   - Tell me what it says

2. **Site shows 404?**
   - Wait 3-5 minutes (first deployment is slow)
   - Clear browser cache (Ctrl+Shift+Delete)
   - Try a different browser

3. **Upload doesn't work?**
